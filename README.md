# Lonas_Max_Measured

CAD-style 2-point measuring plugin for **3ds Max 2025**. Version 0.7.

Scene units: centimetres recommended.

## Install

1. Clone or unzip this folder.
2. In 3ds Max: **Scripting > Run Script... > Install.ms**
3. **Customize > Customize User Interface > Toolbars**  
   Category: `Lonas_Max_Measured` — drag **Lonas_Max_Measured** onto a toolbar.

## Help / About

Open the floater and use **Help / About**:

- Language: English or Türkçe
- Feature list for this version

## Use

Open the floater, pick **2-Point Distance** (vertex magnet snap), or **Bounding Box** on a selected object.

- Click near a corner; the measure locks to the vertex.
- Settings edit the selected tape; if nothing is selected they are defaults for the next new measure.
- Text dir: Horizontal / Vertical. Mirror text if it must read flipped.
- Line X/Y/Z moves the dimension line. Arrow size / width as needed.
- Delete the group to remove spline + text together.
